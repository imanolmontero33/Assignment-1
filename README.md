The COLORS application allows an user to register an account where they can create a list of colors that will be saved to their account which can be searched through later. 
It uses GitHub for version control, DigitalOcean for app hosting, GoDaddy for domain hosting, and MySQL for database implementations. 
The application can be run and accessed by going to the bob.monster domain and simply creating an account. 
Current limitations include inability to access the app outside of the site.
